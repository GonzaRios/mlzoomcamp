# Machine Learning Zoomcamp

This repository contains my solutions for the **Machine Learning Zoomcamp** course by [DataTalks.Club](https://datatalks.club/).

## About the course

The course consists of **10 thematic Machine Learning units**, designed to teach the full *end to end* workflow: from the notebook all the way to model deployment. In addition to the units, it includes **1 midterm project** and **2 final (capstone) projects**.

## Thematic units

| # | Unit |
|---|------|
| 1 | Introduction to Machine Learning |
| 2 | Machine Learning for Regression |
| 3 | Machine Learning for Classification |
| 4 | Evaluation Metrics for Classification |
| 5 | Deploying Machine Learning Models |
| 6 | Decision Trees and Ensemble Learning |
| 7 | *Midterm project* |
| 8 | Neural Networks and Deep Learning |
| 9 | Serverless Deep Learning |
| 10 | Kubernetes |

> Note: unit 7 corresponds to the midterm project (that's why there is no Homework 7). The **2 final projects** (capstones) are developed after completing the units.
